# 생활한자 따라쓰기

일상생활에서 자주 보는 한자(입구·출구·요일·가족·장소·안내 표지판 등) 95개 낱말, 219자를
손가락으로 따라 쓰고 채점받는 모바일 웹앱입니다. 폰에 설치(PWA)하면 인터넷 없이도 쓸 수 있습니다.

**바로 쓰기:** https://sinaboro.github.io/daily-hanja/

## 폰에 앱으로 설치하기 (갤럭시)
1. 위 링크를 카카오톡 등으로 받아 누릅니다.
2. 카톡 브라우저 오른쪽 위 `⋮` → **다른 브라우저로 열기** → Chrome 또는 삼성 인터넷
3. **앱 설치**(Chrome) 또는 메뉴 → **현재 페이지 추가 → 홈 화면**(삼성 인터넷)

## 기능
- 따라쓰기 / 보고쓰기 / 외워쓰기 세 가지 모드, 획 채움·정확도 채점
- 훈음·낱말 읽기 음성(TTS), 주제별 목록과 검색, 진도 저장(기기에 저장)
- 오프라인 실행, 연습하는 동안 화면 켜 두기

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (데이터는 `RAW` 안에 `한자\|읽기\|훈음\|뜻` 형식) |
| `manifest.json` | 앱 이름·아이콘·전체 화면 설정 |
| `sw.js` | 오프라인 캐시 (내용을 고치면 `VERSION`을 올릴 것) |
| `fonts/` | 쓰인 한자만 담은 Noto Serif KR 글꼴 (SIL OFL 1.1) |

낱말을 추가하면 새 한자가 글꼴에 없을 수 있으니 글꼴 서브셋도 다시 만들어야 합니다.
