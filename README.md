# 생활한자 따라쓰기

일상생활에서 자주 보는 한자(입구·출구·요일·가족·장소·안내 표지판 등) 95개 낱말, 219자를
손가락으로 따라 쓰고 채점받는 모바일 웹앱입니다. 폰에 설치(PWA)하면 앱처럼 아이콘이 생기고,
인터넷 없이도 쓸 수 있습니다.

**앱 주소:** https://sinaboro.github.io/daily-hanja/

> 앱스토어(플레이스토어)에 올린 앱이 아니라, 웹 주소를 폰에 **설치**하는 방식입니다.
> 설치 파일(APK)을 받을 필요가 없고, 개인정보나 권한을 요구하지 않습니다.

## 1. 설치하기 전에

- **처음 설치할 때 한 번만** 인터넷(와이파이 또는 데이터)이 필요합니다. 용량은 약 0.2MB입니다.
- 갤럭시는 **Chrome**이나 **삼성 인터넷**, 아이폰은 **Safari**로 설치해야 합니다.
  카카오톡·네이버 앱 안의 브라우저에서는 설치 메뉴가 나오지 않습니다.
- 메뉴 이름은 폰 기종과 브라우저 버전에 따라 조금 다를 수 있습니다.
  (예: "앱 설치" / "홈 화면에 추가" / "설치")

## 2. 카카오톡으로 링크 받기

1. 카카오톡 채팅방에서 아래 주소를 보냅니다. (나와의 채팅에 보내도 됩니다)
   ```
   https://sinaboro.github.io/daily-hanja/
   ```
2. 링크를 누르면 **카카오톡 안의 브라우저**로 열립니다. 여기서는 설치가 안 되므로 다른 브라우저로 옮깁니다.
3. 화면 오른쪽 위(또는 아래)의 **`⋮` (점 세 개)** 를 누릅니다.
4. **다른 브라우저로 열기**를 누릅니다.
5. 브라우저 선택 창이 나오면 **Chrome**(또는 삼성 인터넷)을 고릅니다.
   - "항상" / "한 번만"을 묻는다면 **한 번만**을 눌러도 됩니다.
6. 이어서 아래 3번(Chrome) 또는 4번(삼성 인터넷)을 따라 합니다.

> 링크를 길게 눌러 **복사**한 뒤, Chrome 주소창에 직접 붙여 넣어도 됩니다.

## 3. 갤럭시 — Chrome으로 설치 (권장)

1. Chrome에서 앱 주소를 엽니다. 화면에 "生活漢字 따라쓰기"가 나오면 정상입니다.
2. 앱 화면 맨 위 제목 옆에 빨간 **⬇ 앱 설치** 버튼이 보이면 누르고 5번으로 넘어갑니다.
   - 이 버튼은 Chrome이 "설치할 수 있다"고 확인한 뒤에 나타나므로, 처음 열 때는 몇 초 걸리거나
     화면을 한두 번 눌러야 나올 수 있습니다.
   - Chrome의 화면 아래쪽 설치 안내는 **뜨지 않는 경우가 많습니다.** 안 떠도 정상입니다.
3. 버튼이 없으면 Chrome 오른쪽 위 **`⋮`** 를 누릅니다.
4. 메뉴에서 **앱 설치**를 누릅니다.
   - 메뉴에 "앱 설치"가 없고 **홈 화면에 추가**만 있다면 그것을 누릅니다.
5. 확인 창에서 **설치**를 누릅니다.
6. 잠시 뒤 홈 화면(또는 앱스 화면)에 빨간 **漢** 아이콘의 **생활한자**가 생깁니다.
   - 홈 화면에 안 보이면 화면을 위로 밀어 **앱스 화면**에서 찾아 보세요.
   - 길게 눌러 홈 화면으로 끌어다 놓을 수 있습니다.

## 4. 갤럭시 — 삼성 인터넷으로 설치

1. 삼성 인터넷에서 앱 주소를 엽니다.
2. 주소창 오른쪽에 **설치 아이콘(아래 화살표가 있는 상자 모양)** 이 보이면 누르고 **설치**를 누릅니다.
3. 아이콘이 없으면 화면 아래 **`≡` (메뉴)** 를 누릅니다.
4. **현재 페이지 추가** → **홈 화면**을 누릅니다.
5. 이름이 "생활한자"로 나오면 그대로 **추가**를 누릅니다.
6. 홈 화면에 **생활한자** 아이콘이 생깁니다.

## 5. 아이폰·아이패드 — Safari로 설치

1. 카카오톡에서 링크를 연 뒤, 오른쪽 아래 **나침반(Safari) 아이콘** 또는 `⋯` → **Safari로 열기**를 누릅니다.
2. Safari 아래쪽(아이패드는 위쪽)의 **공유 버튼(네모에서 위쪽 화살표)** 을 누릅니다.
3. 목록을 위로 밀어 **홈 화면에 추가**를 누릅니다.
4. 오른쪽 위 **추가**를 누릅니다.

> 아이폰은 Chrome에서는 설치되지 않습니다. 반드시 Safari를 쓰세요.

## 6. PC(윈도우)에서 설치

1. Chrome 또는 Edge에서 앱 주소를 엽니다.
2. 주소창 오른쪽 끝의 **설치 아이콘(모니터와 아래 화살표)** 을 누릅니다.
   - Edge는 `⋯` → **앱** → **이 사이트를 앱으로 설치**를 누릅니다.
3. **설치**를 누르면 시작 메뉴에 "생활한자 따라쓰기"가 생깁니다.

> PC에서는 마우스로 쓰거나, 펜 태블릿·터치스크린을 쓰면 편합니다.
> 키보드 단축키: `←` `→` 이전/다음, `Enter` 채점, `Ctrl+Z` 되돌리기, `Delete` 지우기

## 7. 설치가 잘 됐는지 확인하기

- 아이콘으로 실행했을 때 **주소창 없이 전체 화면**으로 열리면 앱으로 설치된 것입니다.
- **비행기 탑승 모드**를 켜고 앱을 실행해 보세요. 그래도 열리면 오프라인 준비가 끝난 것입니다.
  (설치 후 인터넷이 연결된 상태로 **한 번은 앱을 열어** 두어야 합니다.)

## 8. 새 버전 받기 (업데이트)

- 따로 할 일은 없습니다. 인터넷이 연결된 상태로 앱을 열면 새 버전을 자동으로 받습니다.
- 바로 반영되지 않으면 앱을 **완전히 닫았다가**(최근 앱 목록에서 위로 밀기) **다시 열어** 보세요.
  보통 1~2번 다시 열면 새 버전이 나옵니다.

## 9. 진도 기록에 대해 꼭 알아 둘 점

- 점수와 진도는 **그 폰의 그 브라우저 안에만** 저장됩니다. 서버로 보내지 않습니다.
- 그래서 다음과 같은 경우 기록이 **따로** 저장되거나 **지워집니다.**
  - 다른 폰이나 다른 브라우저에서 열면 기록이 처음부터 시작됩니다.
  - 브라우저의 **인터넷 사용 기록 삭제 → 쿠키 및 사이트 데이터**를 지우면 기록도 지워집니다.
  - 앱을 지우고 다시 설치해도 기록이 지워질 수 있습니다.
- 앱 아이콘과 브라우저에서 연 페이지는 같은 기록을 같이 씁니다.

## 10. 앱 지우기

- **갤럭시:** 아이콘을 길게 누름 → **설치 삭제**(또는 **삭제**)
- **아이폰:** 아이콘을 길게 누름 → **앱 삭제** → **홈 화면에서 삭제**
- **PC:** 앱을 실행 → 오른쪽 위 `⋮` → **제거**

## 11. 문제가 생겼을 때

| 증상 | 해결 방법 |
|---|---|
| Chrome에서 열었는데 아래쪽 "앱 설치" 안내가 안 뜸 | 정상입니다. 앱 위쪽 **⬇ 앱 설치** 버튼이나 Chrome **⋮ → 앱 설치(홈 화면에 추가)** 로 설치하세요. 앱의 ⚙ 설정 맨 아래에도 지금 쓰는 브라우저에 맞는 설치 방법이 나옵니다. |
| 메뉴에 "앱 설치"·"홈 화면에 추가"가 없음 | 카카오톡·네이버 앱 안의 브라우저일 가능성이 큽니다. 2번처럼 **다른 브라우저로 열기**를 하세요. |
| 설치했는데 아이콘이 안 보임 | 앱스 화면을 확인하거나, 설정 → 애플리케이션에서 "생활한자"를 찾아보세요. |
| 아이콘을 누르면 주소창이 보이는 브라우저로 열림 | "앱 설치"가 아니라 바로가기로 추가된 경우입니다. 지우고 Chrome의 **앱 설치**로 다시 설치하세요. |
| 글씨를 쓰면 화면이 움직이거나 새로고침됨 | 바둑판 칸 **안에서** 써 주세요. 칸 밖을 끌면 화면이 스크롤됩니다. |
| 🔊 소리가 안 남 | 폰의 미디어 음량을 올리고, 설정 → 일반 → **텍스트 음성 변환(TTS)** 에서 한국어 음성이 설치되어 있는지 확인하세요. |
| 화면이 자꾸 꺼짐 | 앱의 ⚙ 설정에서 **연습하는 동안 화면 켜 두기**를 켜세요. (절전 모드에서는 안 될 수 있습니다) |
| 새 단어가 추가됐다는데 안 보임 | 8번처럼 앱을 완전히 닫았다가 다시 여세요. |

## 기능
- 따라쓰기 / 보고쓰기 / 외워쓰기 세 가지 모드, 획 채움·정확도 채점
- 훈음·낱말 읽기 음성(TTS), 주제별 목록과 검색, 진도 저장(기기에 저장)
- 오프라인 실행, 연습하는 동안 화면 켜 두기
- 갤럭시 폴드: 접은 화면·펼친 화면, 가로·세로 모두 지원

## 파일
| 파일 | 설명 |
|---|---|
| `index.html` | 앱 전체 (데이터는 `RAW` 안에 `한자\|읽기\|훈음\|뜻` 형식) |
| `manifest.json` | 앱 이름·아이콘·전체 화면 설정 |
| `sw.js` | 오프라인 캐시 (내용을 고치면 `VERSION`을 올릴 것) |
| `fonts/` | 쓰인 한자만 담은 Noto Serif KR 글꼴 (SIL OFL 1.1) |

낱말을 추가하면 새 한자가 글꼴에 없을 수 있으니 글꼴 서브셋도 다시 만들어야 합니다.
